# 🧾 Telegram-бот для перевірки оплат мешканців
Цей Telegram-бот дозволяє переглядати інформацію про мешканців, кількість мішків, стан оплат та здійснювати пошук за ПІБ або номером договору.

## 🔧 Налаштування
1. Увімкни Google Sheets API і Google Drive API в Google Cloud.
- Перейдіть у Google Cloud Console.
- Створіть новий проект або виберіть вже створений.
- У лівому меню оберіть APIs & Services > Library.
- У пошуку введіть:
Google Sheets API — відкрийте й натисніть Enable.
Google Drive API — так само відкрийте й Enable.

2. Створи Service Account і згенеруй `credentials.json`.
- У меню зліва перейдіть до APIs & Services > Credentials.
- Натисніть + CREATE CREDENTIALS → Service Account.
- Введіть назву (наприклад telegram-bot-access) і натисніть Create and Continue.
- На кроці Grant access нічого не обирайте — просто Done.

3. Завантаження credentials.json 
- У списку сервісних акаунтів натисніть на свій створений акаунт.
- У вкладці Keys натисніть Add Key → Create new key.
- Оберіть тип JSON → натисніть Create.
- Файл credentials.json буде завантажено на компʼютер.
- Збережи його у своєму проєкті GitHub (але НЕ пуш у репозиторій! Додай до .gitignore).

4. Додай сервісному обліковому запису права на редагування таблиці.


## 🚀 Запуск:
```
pip install aiogram gspread oauth2client python-dotenv
python main.py
```

## 📦 Функціонал
 - Обрати населений пункт та вулицю для перегляду мешканців
 - Пошук мешканця за ПІБ або номером договору
 - Відображення оплати за поточний місяць:
   - ✅ ОПЛАЧЕНО — якщо оплачено повну вартість
   - ❗️УВАГА — якщо оплачено частково (відображається еквівалент у мішках)
   - ❌ НЕ ОПЛАЧЕНО — якщо немає оплати
 - Кнопки Назад та Головне меню на кожному етапі
 - Кнопка 🚀 РОЗПОЧАТИ для запуску без введення /start

## 🛠 Структура таблиці в Google Sheets
- Лист 1: Населені пункти. 
- Лист 2: Вулиці. 
- Інші листи: окремо для кожної вулиці, де вказано:
  - ПІБ
  - № будинку
  - номер договору
  - кількість мішків
  - суми оплати по місяцях (українською: Січень, Лютий, ...)

# 🧩 Команди
 - /start  - Запуск бота
 - 🚀 РОЗПОЧАТИ - Альтернатива /start для зручного старту
 - Обрати населений пункт -	Почати перегляд за місцем проживання
 - Пошук за договором -	Пошук мешканця за ПІБ або номером договору
 - 🔙 Назад - Повернутися на попередній етап
 - 📝 Головне меню	- Повернутися до головного меню
